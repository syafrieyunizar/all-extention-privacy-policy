e-Klaim Koding Assistant

Terakhir diperbarui: 19 Juli 2026

Kebijakan ini menjelaskan cara ekstensi Chrome e-Klaim Koding Assistant ("Ekstensi") menangani data ketika membantu pengguna membaca dokumen medis, menghasilkan saran koding ICD, menelaah kelengkapan file, dan mengisi koding ke halaman e-Klaim.

Ringkasan perlindungan data
  • PDF diproses lebih dahulu pada perangkat pengguna menggunakan PDF.js.
  • Halaman scan atau gambar diproses dengan OCR lokal dan dapat ditinjau pengguna.
  • Identitas pasien, dokter, dan fasilitas kesehatan disensor secara lokal sebelum pemrosesan AI.
  • PDF mentah tidak dikirim ke penyedia AI ketika teks dapat diekstrak atau di-OCR secara lokal.
  • Teks medis tersensor dapat dikirim ke Supabase dan penyedia AI pilihan pengguna.
  • Pengembang tidak menjual data pengguna atau menggunakannya untuk periklanan maupun kelayakan kredit.

Data yang Ditangani

Informasi medis dan isi dokumen

Ekstensi menangani isi PDF resume atau rekam medis, termasuk diagnosis, gejala, hasil pemeriksaan, terapi, tindakan, dan informasi klinis lain. Data digunakan hanya untuk fungsi yang diminta pengguna, seperti ekstraksi teks, saran ICD-10/ICD-9, pencarian knowledge BPJS, dan analisis kelengkapan file.

Informasi identitas

Dokumen dapat memuat nama pasien, NIK, nomor rekam medis, nomor SEP, alamat, tanggal lahir, nomor telepon, nama dokter, dan identitas fasilitas kesehatan. Ekstensi memproses informasi tersebut secara lokal untuk:

  • menampilkan identitas pasien pada hasil;
  • memeriksa kecocokan pasien sebelum mengisi halaman e-Klaim;
  • menyensor identitas sebelum teks dikirim ke layanan AI; dan
  • menyimpan riwayat lokal bila pengguna memakai fitur riwayat.

Ekstensi dirancang agar identitas tersebut tidak disertakan dalam teks yang dikirim ke AI. Karena format dokumen rumah sakit dapat berbeda, pengguna tetap harus meninjau hasil penyensoran dan keluaran sebelum digunakan.

Informasi autentikasi dan konfigurasi

Ekstensi dapat menangani API key personal, endpoint AI, username, password, token sesi, ID perangkat, provider, model, dan preferensi tampilan. API key personal disimpan pada penyimpanan lokal Chrome dan digunakan hanya untuk endpoint AI yang dipilih pengguna. Kredensial mode admin dikirim melalui HTTPS ke Supabase Edge Function untuk autentikasi. Password login tidak dipertahankan dalam sesi lokal setelah login berhasil; token sesi disimpan secara lokal selama masih berlaku.

Konten situs yang sedang digunakan

Atas tindakan pengguna, Ekstensi dapat membaca PDF dari tab aktif serta elemen terbatas pada halaman e-Klaim, seperti nomor SEP atau nomor rekam medis, untuk memeriksa kecocokan pasien dan mengisi kode. Ekstensi tidak membuat riwayat penelusuran, tidak menggunakan analytics, dan tidak memantau aktivitas browsing pengguna.

Pemrosesan dan Penyimpanan Lokal

Ekstensi menggunakan chrome.storage.local dan IndexedDB untuk menyimpan pengaturan, state hasil generate, sesi admin, dan riwayat lokal. PDF yang disimpan dalam state atau riwayat lokal dienkripsi menggunakan AES-GCM. Kunci enkripsi juga berada di penyimpanan lokal profil Chrome, sehingga enkripsi ini mengurangi paparan data tersimpan tetapi bukan pengganti pengamanan perangkat atau profil Chrome.

Data lokal tetap tersimpan sampai pengguna menghapus sesi atau riwayat, menghapus data Ekstensi dari Chrome, atau mencopot Ekstensi. Pengguna dapat menghapus satu riwayat maupun mereset sesi melalui antarmuka Ekstensi.

Data yang Dikirim ke Layanan Eksternal

Untuk menjalankan fungsi yang diminta pengguna, Ekstensi dapat mengirim data berikut melalui HTTPS:

  1. Supabase Edge Function: teks medis tersensor atau keyword turunannya untuk pencarian knowledge BPJS; prompt tersensor untuk pemrosesan AI dalam mode admin; serta data autentikasi dan sesi admin.
  2. Penyedia AI pilihan pengguna: teks medis tersensor, prompt, dan konfigurasi permintaan untuk menghasilkan saran koding atau analisis kelengkapan. Dalam mode personal, API key pengguna dikirim langsung ke endpoint provider yang dipilih.
  3. Situs e-Klaim aktif: hasil koding dan identitas pembanding dimasukkan hanya setelah tindakan pengguna dan pemeriksaan kecocokan SEP atau nomor rekam medis.

Penyedia AI dapat berupa Gemini, Sumopod, AIMurah, Genfity, X5Lab, atau endpoint OpenAI-compatible lain yang dikonfigurasi pengguna. Penggunaan dan retensi data oleh penyedia tersebut tunduk pada kebijakan privasi dan ketentuan masing-masing penyedia. Pengembang Ekstensi tidak menggunakan dokumen medis untuk melatih model AI milik pengembang.

Tautan dukungan dapat membuka layanan pihak ketiga seperti Lynk.id atau WhatsApp. Ekstensi tidak mengirim dokumen medis secara otomatis ke layanan dukungan tersebut.

Berbagi dan Penjualan Data

Pengembang tidak menjual data pengguna. Data tidak digunakan atau dipindahkan untuk tujuan yang tidak berhubungan dengan fungsi utama Ekstensi, untuk periklanan, atau untuk menentukan kelayakan kredit maupun pemberian pinjaman. Pemindahan data hanya dilakukan kepada layanan yang diperlukan untuk fungsi pilihan pengguna sebagaimana dijelaskan di atas.

Keamanan

Ekstensi menggunakan pemrosesan PDF dan OCR lokal, penyensoran identitas sebelum pemrosesan AI, HTTPS untuk komunikasi jaringan, serta AES-GCM untuk PDF yang disimpan secara lokal. Tidak ada metode yang dapat menjamin keamanan mutlak. Pengguna bertanggung jawab menjaga keamanan perangkat, akun Chrome, kredensial, dan endpoint AI yang dipilih.

Kontrol Pengguna

  • Memilih mode API key personal atau admin.
  • Meninjau dan mengedit hasil OCR sebelum diproses.
  • Meninjau serta mengedit hasil koding dan analisis.
  • Menghapus file dari sesi aktif dan menghapus riwayat lokal.
  • Mereset sesi atau mencopot Ekstensi untuk menghapus data lokal terkait.

Penggunaan yang Dibatasi

Penggunaan data yang diperoleh dari Google APIs mengikuti Chrome Web Store User Data Policy, termasuk persyaratan penggunaan terbatas. Ekstensi menggunakan data hanya untuk menyediakan dan meningkatkan fungsi yang terlihat dan diminta pengguna.

Perubahan Kebijakan

Kebijakan ini dapat diperbarui ketika fungsi atau alur data Ekstensi berubah. Tanggal pembaruan terbaru akan dicantumkan di bagian atas halaman ini.
