eKlaim x eRM Helper RSBHHB

Terakhir diperbarui: 18 November 2026 | Versi ekstensi 2.0.2

Ekstensi ini membantu tim Casemix memantau resume medis dan kelengkapan berkas pasien. Data pasien diproses pada perangkat dan, sesuai fitur yang digunakan, dapat dikirim ke Supabase atau diterbitkan sebagai snapshot terenkripsi di GitHub Pages.

1. Tujuan dan ruang lingkup

Ekstensi membantu pengguna yang berwenang bekerja dengan sistem e-Klaim dan rekam medis elektronik (e-RM): memeriksa resume, menampilkan status dan catatan, memantau dashboard per bulan, serta membantu navigasi dan pencarian data. Kebijakan ini menjelaskan data yang diproses ekstensi, termasuk data yang hanya disimpan di perangkat.

2. Data yang diproses

  • Identitas dan administrasi pasien: nama, nomor SEP, nomor rekam medis, tanggal masuk dan pulang, ruangan, serta dokter penanggung jawab pelayanan (DPJP).
  • Data kesehatan dan berkas: informasi pada halaman atau dokumen e-RM yang diperlukan untuk pemeriksaan, status resume medis dan kelengkapan berkas, serta catatan yang dimasukkan pengguna.
  • Identitas dan autentikasi pengguna: nama atau identitas pengedit yang dikonfigurasi, email dan password akun admin Supabase, token sesi, serta password yang digunakan untuk membaca catatan lama atau membuka dan menerbitkan dashboard. Password admin dikirim ke Supabase untuk autentikasi. Password pembaca digunakan di perangkat untuk membuka atau mengenkripsi snapshot.
  • Konfigurasi dan data teknis: alamat Supabase, anon key, status sinkronisasi, pemetaan dokumen, dan alamat halaman atau dokumen e-Klaim/e-RM yang diperlukan untuk menjalankan fitur. Ekstensi tidak dirancang untuk mengumpulkan seluruh riwayat penjelajahan.
  • Kontak dan data pilihan pengguna: nama dan nomor kontak admin yang dikonfigurasi untuk fitur WhatsApp, serta data yang dipilih pengguna untuk disalin atau disiapkan sebagai pesan.

3. Cara data digunakan dan disimpan

Data digunakan untuk menampilkan status pasien, mengelola catatan dan antrean sinkronisasi, mengambil data SEP serta DPJP, membantu pemeriksaan resume, dan menyusun dashboard sesuai bulan tanggal pulang. Ekstensi memproses data dari halaman dan dokumen yang digunakan dalam alur kerja tersebut.

  • Perangkat pengguna: konfigurasi, cache SEP, catatan, status, antrean, dan data dashboard dapat disimpan di penyimpanan lokal browser. Sebagian data dan catatan baru disimpan dalam bentuk teks biasa; tidak semua data lokal dienkripsi oleh ekstensi.
  • Supabase: data SEP, DPJP, ruangan, status warning, catatan, dan data pendukung tertentu dapat disinkronkan dengan proyek Supabase yang dikonfigurasi. Penarikan pembaruan daftar dilakukan melalui tombol pengguna; perubahan tertentu dapat dikirim melalui antrean sinkronisasi. Catatan baru tidak dienkripsi oleh ekstensi sebelum disimpan di database. Catatan lama yang sebelumnya dienkripsi dapat dibaca menggunakan password lama.
  • Dashboard: data disiapkan di perangkat. Saat admin memilih bulan dan menekan tombol penerbitan, snapshot bulan tersebut dienkripsi di perangkat dengan password pembaca dan dikirim melalui fungsi Supabase ke repositori GitHub untuk ditampilkan di GitHub Pages. Snapshot tidak diperbarui secara realtime atau diterbitkan otomatis.

Saat fitur dashboard dan penandaan lengkap digunakan, admin diautentikasi melalui Supabase. Akses terhadap data pada tabel e-Klaim yang ada bergantung pada konfigurasi dan kebijakan proyek Supabase; beberapa alur lama menggunakan anon key dan tidak memiliki pembatasan per pengguna yang sama dengan dashboard admin.

4. Penerima dan pembagian data

  • Supabase: memproses autentikasi dan permintaan database, serta menjalankan fungsi penerbitan dashboard sesuai konfigurasi pengelola.
  • GitHub dan GitHub Pages: menerima dan menyimpan file snapshot dashboard yang telah dienkripsi. Repositori dan file terenkripsinya dapat diakses publik. Orang yang memiliki file dan password pembaca dapat membuka isinya; versi file lama dapat tetap tersedia dalam riwayat GitHub.
  • WhatsApp: jika pengguna memilih fitur Chat Admin, ekstensi membuka tautan WhatsApp yang berisi nomor tujuan dan teks yang disiapkan. Pengguna perlu memeriksa isi dan penerima sebelum mengirim pesan.
  • Sistem rumah sakit: ekstensi berinteraksi dengan server e-Klaim dan e-RM yang digunakan dalam pekerjaan pengguna.
  • Halaman kebijakan ini: browser mengakses GitHub Pages dan dapat meminta font dari Google Fonts; penyedia tersebut dapat menerima data teknis koneksi sesuai kebijakan masing-masing.

Ekstensi tidak dirancang untuk menjual data pengguna, menggunakannya untuk iklan, atau menggunakannya untuk penilaian kredit. Penggunaan dan pembagian data dibatasi untuk menyediakan fungsi yang dijelaskan di sini dan keperluan operasional terkait.

5. Keamanan dan batasan

Snapshot dashboard yang diterbitkan dienkripsi dengan AES-GCM menggunakan kunci yang diturunkan dari password pembaca. Kekuatan password, pengelolaan akses Supabase, keamanan perangkat dan pengaturan jaringan tetap penting. Mengganti password tidak menghapus salinan snapshot lama dari riwayat repositori atau salinan yang sudah diunduh.

Ekstensi terhubung ke Supabase menggunakan HTTPS. Sebagian alamat e-Klaim/e-RM internal yang dikonfigurasi menggunakan HTTP; keamanan lalu lintas pada jaringan internal bergantung pada pengaturan jaringan dan sistem rumah sakit. Password pembaca dashboard tidak membatasi akses ke database Supabase.

6. Penyimpanan, penghapusan, dan kontrol

Saat fitur pengambilan data SEP digunakan, cache lokal tertentu untuk SEP lama dapat dibersihkan berdasarkan usia SEP sekitar 60 hari. Pembersihan tersebut tidak menghapus data dashboard lokal maupun data yang tersimpan di Supabase atau GitHub. Data lokal juga dapat dihapus melalui pengaturan browser atau dengan menghapus ekstensi; tindakan ini tidak menghapus salinan cloud.

Pengelola proyek mengatur masa simpan dan penghapusan data di Supabase, termasuk cadangan dan log layanan. Penghapusan file dari cabang utama GitHub tidak otomatis menghapus riwayat Git, cadangan, atau salinan yang sudah diperoleh penerima. Untuk permintaan akses, koreksi, atau penghapusan data, hubungi tim IT/Casemix RSBHHB.

7. Izin browser

  • storage dan unlimitedStorage: menyimpan pengaturan, cache, antrean, serta data dashboard di browser.
  • tabs dan scripting: membuka dan mengelola tab yang digunakan dalam alur kerja, serta membantu pencarian pada halaman e-RM.
  • clipboardWrite: mendukung penyalinan yang diminta pengguna pada fitur e-RM dan konfigurasi ekstensi.
  • Izin host: mengakses alamat e-Klaim, e-RM, dan Supabase yang tercantum pada ekstensi. Izin tambahan dapat diminta untuk alamat Supabase yang dikonfigurasi pengguna.

8. Kontak dan perubahan kebijakan
