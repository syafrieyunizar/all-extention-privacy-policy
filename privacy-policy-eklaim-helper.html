Kebijakan Privasi Resmi

eKlaim x eRM Helper RSBHHB

Terakhir diperbarui: 21 Juli 2026 | Versi 1.2.3

🔒 Komitmen Keamanan: Ekstensi ini dirancang khusus untuk tim internal Casemix RSBHHB. Seluruh data medis dan catatan sensitif dienkripsi secara lokal sebelum dikirimkan ke cloud server.

1. Pendahuluan

Ekstensi Chrome eKlaim x eRM Helper RSBHHB dibuat untuk membantu produktivitas tim Casemix RSBHHB dalam memadukan dan memverifikasi data antara sistem e-Klaim BPJS Kesehatan dengan sistem Rekam Medis Elektronik (e-RM) rumah sakit. Kami menghargai privasi dan keamanan data pasien serta pengguna ekstensi ini.

2. Data yang Dikumpulkan dan Diproses

Ekstensi ini memproses beberapa jenis informasi teknis dan operasional untuk dapat berfungsi:

  • Data Pengidentifikasi Berkas Pasien: Nomor SEP (Surat Elegabilitas Peserta), Nomor Rekam Medis (RM), dan Nama Pasien yang tampil pada halaman kerja aktif.
  • Catatan Hambatan & Kelengkapan Resume Medis: Teks catatan medis internal, status kelengkapan resume, dan penandaan dokter penanggung jawab (DPJP).
  • Identitas Pengguna: Nama/ID pengedit (dikonfigurasi sendiri oleh pengguna di menu Pengaturan) untuk keperluan audit log internal tim.
  • Data Konfigurasi Koneksi: URL Supabase, Anon Key, dan Kata Sandi Enkripsi.

3. Penyimpanan dan Enkripsi Data

  • Penyimpanan Lokal (Local Device): Kata sandi enkripsi, riwayat penyalinan clipboard, dan preferensi pengaturan disimpan 100% secara lokal pada browser pengguna menggunakan chrome.storage.local dan tidak pernah dikirimkan ke pihak ketiga mana pun.
  • Enkripsi Terdistribusi (Cloud Storage): Seluruh teks catatan medis yang dikirimkan ke cloud (database Supabase milik rumah sakit) dienkripsi terlebih dahulu di perangkat pengguna menggunakan algoritma kriptografi AES-GCM / RC4. Hanya pengguna yang memiliki kata sandi enkripsi yang sama yang dapat membaca isi catatan tersebut.

4. Penggunaan Izin Browser (Permissions)

Ekstensi ini hanya meminta izin minimal yang diperlukan untuk beroperasi:

  • storage: Digunakan untuk menyimpan preferensi konfigurasi dan data cache secara lokal.
  • Host Permissions (http://172.16.0.5/* & http://172.16.0.3/*): Digunakan untuk menjalankan content script yang menyuntikkan tombol pembantu dan penanda warna pada antarmuka web e-Klaim dan e-RM internal rumah sakit.

5. Pihak Ketiga & Pembagian Data

Kami TIDAK PERNAH menjual, menyewakan, membagikan, atau memperjualbelikan data apa pun dari ekstensi ini kepada pihak ketiga, pengiklan, atau penyedia analitik luar. Data hanya mengalir antara browser lokal pengguna dengan server database Supabase yang dikelola sendiri oleh tim rumah sakit.

6. Hak Pengguna

Pengguna memiliki kontrol penuh terhadap data lokal mereka. Seluruh data penyimpanan lokal dapat dihapus kapan saja melalui menu pengaturan browser atau dengan mengklik tombol "Reset Riwayat Salinan" pada panel ekstensi.

7. Hubungi Kami

Jika Anda memiliki pertanyaan terkait kebijakan privasi atau penggunaan ekstensi ini, silakan hubungi tim IT / Casemix RSBHHB atau kirimkan laporan melalui repositori proyek.
